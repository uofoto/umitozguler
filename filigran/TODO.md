# Filigran — Teslim Maddeleri

## Cihaz üzerinde fotoğraf yükleme ve geçerlilik kontrolleri
- [x] Kullanıcı cihazdan sürükle-bırak veya dosya seçimiyle fotoğraf yükleyebilmeli.
- [x] Uygulama temel dosya/geçerlilik kontrollerini yapmalı ve desteklenmeyen dosyaları anlaşılır biçimde bildirmeli.

## Görünmez imza oluşturma
- [x] Kullanıcı sahiplik bilgisi ya da kısa dijital imza girebilmeli.
- [x] Kullanıcı gömme yoğunluğunu ayarlayabilmeli ve dayanıklılık–görsel kalite dengesi hakkında anlaşılır geri bildirim görebilmeli.
- [x] İmza, Exif metadatasından bağımsız biçimde, tarayıcı içinde fotoğraf piksel verisine görünmez şekilde gömülmeli.
- [x] İşlem öncesi ve sonrası görsel yakınlaştırılarak karşılaştırılabilmeli ve işlem durumu gösterilmeli.
- [x] Filigranlı görsel uygun kalite ve dosya biçimiyle cihaza indirilebilmeli.

## Doğrulama
- [x] Ayrı doğrulama akışında görsel yüklenebilmeli.
- [x] Uygulama gömülü imzayı arayabilmeli ve bulunan sahiplik bilgisini sonuç ekranında gösterebilmeli.

## Gizlilik ve PWA deneyimi
- [x] Fotoğrafların sunucuya gönderilmediğini belirten gizlilik durumu görünür olmalı.
- [x] İşlemler tamamen cihaz üzerinde çalışmalı.
- [x] Uygulama kurulabilir PWA olmalı ve temel gömme/doğrulama akışları çevrimdışı kullanılabilmeli.
- [x] Arayüz Türkçe, masaüstü ve mobil uyumlu olmalı.
