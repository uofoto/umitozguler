FILIGRAN PWA - GITHUB YAYIN DOSYALARI

Bu arşiv uygulama kurulumu için APK veya HTML indirme paketi değildir. PWA, HTTPS sitesinden tarayıcının kendi kurulum işleviyle kurulur.

Yükleme:
1. Bu ZIP'i açın.
2. İçindeki index.html, assets klasörü, manifest.webmanifest, filigran-mark.svg, filigran-mark-192.png, filigran-mark-512.png, sw.js ve manus-routes.json dosyalarını GitHub deposundaki mevcut filigran/ klasörünün doğrudan içine yükleyin.
3. ZIP'i veya ZIP içindeki dosyaları yeni bir alt klasörün içine koymayın.
4. Değişiklik GitHub Pages'te yayımlandıktan sonra https://www.umitozguler.com.tr/filigran/ adresini açın.
5. Android Chrome/masaüstü Chrome-Edge'de sayfadaki YÜKLE düğmesine basın. Tarayıcı yerel PWA onayını açar. iPhone/iPad'de Safari'de Paylaş > Ana Ekrana Ekle kullanılır.

Aynı ada sahip mevcut dosyalar varsa yeni sürümle değiştirin. Yeni hash'li assets dosyalarını da ekleyin; index.html bunları çağırır.
