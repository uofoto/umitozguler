FILIGRAN PWA - GITHUB YAYIN DOSYALARI

Bu arşiv APK veya HTML indirme paketi değildir. PWA, HTTPS sitesinden tarayıcının kendi kurulum işleviyle kurulur.

Yükleme:
1. Bu ZIP'i açın.
2. İçindeki index.html, assets klasörü, manifest.webmanifest, filigran-mark.svg, filigran-mark-192.png, filigran-mark-512.png, sw.js ve manus-routes.json dosyalarını GitHub deposundaki mevcut filigran/ klasörünün doğrudan içine yükleyin.
3. Dosyaları yeni bir alt klasörün içine koymayın.
4. Değişiklik yayımlandıktan sonra https://www.umitozguler.com.tr/filigran/ adresini açın.
5. Android Chrome/masaüstü Chrome-Edge'de YÜKLE düğmesi tarayıcının PWA kurulum onayını açar. iPhone/iPad'de Safari'de Paylaş > Ana Ekrana Ekle kullanılır.

Fotoğraf biçimi MIME etiketinden bağımsız olarak içerik imzasıyla kontrol edilir. JPEG/PNG/WebP baytları, cihaz yanlışlıkla image/heic bildirse bile doğru biçiminde kabul edilir.
Aynı ada sahip dosyaları yeni sürümle değiştirin ve yeni hash'li assets dosyalarını da ekleyin.
